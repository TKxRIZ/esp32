📟 ESP32 OLED Firmware

Netzwerk-Infodisplay mit Web-Konfigurationsportal, Dreh-Encoder und drahtlosen Updates. In einer Minute installiert – direkt aus dem Browser, ganz ohne Programmierkenntnisse.

⚠️ Dein Browser unterstützt kein Web Serial. Bitte Chrome oder Edge am Desktop verwenden (nicht Safari/Firefox, nicht am Handy). ⚠️ Installation nur über HTTPS oder localhost möglich.

Funktioniert in Chrome & Edge (Desktop). ESP32 per USB-Kabel anschließen.

So geht's

  1. ESP32 mit einem USB-Datenkabel an den Computer anschließen.
  2. Oben auf „Firmware installieren" klicken.
  3. Im Auswahlfenster den seriellen Port des ESP32 wählen (heißt z. B. CP2102 oder USB Serial) und bestätigen.
  4. Installation abwarten – der ESP startet danach automatisch neu.

Einrichten (nach der Installation)

Die Firmware bringt ein eigenes Einrichtungs-WLAN mit – keine Code-Änderung nötig:

  1. Mit dem WLAN ESP32-Setup verbinden (Handy oder Laptop).
  2. Es öffnet sich automatisch ein Konfigurations-Portal (falls nicht: http://192.168.4.1 aufrufen).
  3. Dein WLAN, den Gerätenamen und weitere Optionen eintragen und speichern.
  4. Fertig – der ESP verbindet sich und zeigt seine IP-Adresse auf dem Display. Das Portal ist danach unter dieser IP bzw. http://<name>.local erreichbar.

Spätere Updates kannst du drahtlos über das Portal (Menüpunkt „OTA-Update") einspielen.

Passende Hardware

BoardESP32 DevKit v1 (ESP32-WROOM-32)
DisplayOLED 128×64, Controller SH1106, I²C
OLED-AnschlussSDA→GPIO21, SCL→GPIO22, VCC→3V3, GND→GND
Dreh-EncoderCLK→GPIO18, DT→GPIO19, SW→GPIO5 (optional)

Hinweis: Diese Firmware ist auf ein SH1106-Display abgestimmt. Bei einem echten SSD1306 kann die Anzeige verschoben sein.
